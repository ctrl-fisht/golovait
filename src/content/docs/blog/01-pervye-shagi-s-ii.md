За 30 минут можно закрыть базу и понять, нужен ли тебе ИИ вообще. План без теории.

## 0–10 мин — первый диалог

Зайди на `chatgpt.com`, вставь:

```
Ты — ассистент новичка. Объясни как работает ChatGPT за 5 пунктов простым языком + 1 пример для ТГ-канала.
```

Сохрани ответ — это твой первый артефакт.

## 10–20 мин — ресерч с источниками

Открой `perplexity.ai`:

```
Топ-5 бесплатных нейронок для картинок в 2026. Сравни качество/цену/лимиты, дай ссылки.
```

Сравни ответы ChatGPT и Perplexity — увидишь разницу.

## 20–30 мин — первая картинка

`ideogram.ai` → промпт:

```
minimal flat illustration, AI chip and books, pastel, text "HELLO AI"
```

Скачай 1 картинку — это обложка для поста.
