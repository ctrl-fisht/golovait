import { Steps } from '@astrojs/starlight/components';

<Steps>

1.  ### ChatGPT или Claude — мозг на аутсорсе
    Зайди на **chatgpt.com** или **claude.ai**. Бесплатно. Вставь:

    ```
    Ты — мой ассистент по ИИ. Объясни мне, как работает ChatGPT, за 5 пунктов, простым языком, с 1 примером использования для новичка.
    ```

2.  ### Perplexity — гугл на стероидах
    Зайди на **perplexity.ai**. Спроси:

    ```
    Найди топ-5 бесплатных нейросетей для генерации картинок в 2026. Сравни по качеству, цене, лимитам. Дай ссылки.
    ```

    Получишь ответ с источниками.

3.  ### Ideogram / Flux — первая картинка
    Зайди на **ideogram.ai** (бесплатно). Вставь:

    ```
    cozy telegram guide cover, minimal flat illustration, books and AI chip, pastel colors, text "AI GUIDE" -- style clean
    ```

    Через 10 сек — 4 варианта. Скачай лучший — это твоя обложка.

</Steps>

:::tip[Чек]
После 3 шагов у тебя: 1 диалог с ИИ, 1 ресерч, 1 картинка. База закрыта.
:::
