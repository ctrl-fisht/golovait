Формула: **Роль + Задача + Контекст + Формат + Ограничения**. Вставь свои данные в `[скобки]`.

### 1. Объясни сложное просто

```
Ты — преподаватель, объясняешь [ТЕМА] человеку без опыта.
Дай: 1) определение 1 предложением 2) аналогию из жизни 3) 3 примера 4) где ошибаются новички.
Пиши просто, без жаргона, до 200 слов.
```

### 2. Пост для ТГ за 60 сек

```
Ты — копирайтер ТГ-канала про [ТЕМА КАНАЛА].
Напиши пост 130-160 слов про [ИДЕЯ]. Структура: крючок 1 строка, 3 тезиса с эмодзи, вывод + вопрос в комменты. Тон: дружелюбный, без воды.
```

### 3. План обучения

```
Составь план изучения [НАВЫК] за 14 дней по 30 мин в день.
Каждый день: теория 10 мин + практика 20 мин + 1 задание. Дай чек-лист прогресса в таблице.
```

### 4. Разбор + улучшение текста

```
Ты — редактор. Вот мой текст: "[ВСТАВЬ ТЕКСТ]".
1) Найди 3 слабых места 2) Перепиши сильнее, сохрани смысл 3) Дай 2 заголовка-крючка.
```

### 5. Идеи контента на неделю

```
Придумай 7 идей постов для ТГ про [ТЕМА] для новичков.
Формат: день | идея | формат (пост/опрос/кружок) | крючок 1 строка. Без банальщины.
```

:::tip[Конструктор]
Собери: `Ты — эксперт по ИИ. Задача: объясни как начать новичку. Формат: список 5 пунктов. Ограничения: до 200 слов, тон дружелюбный.` — и вставь в ChatGPT.
:::
