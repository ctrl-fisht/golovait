ИИ = программа, которая учится на примерах. Показал 1 млн котов — генерит новых котов. Показал тексты — пишет тексты. Магии нет.

## 3 уровня — запомни

- **Классический ИИ** — правила `if/else`. Шахматы 90-х.
- **Машинное обучение** — учится на данных. Рекомендации YouTube.
- **Генеративный ИИ** — создаёт новое. ChatGPT, Midjourney. **Тебе сюда.**

## Как это юзать тебе

Ты не обучаешь модели. Ты **пишешь промпт → получаешь результат**. Навык №1 — правильно просить.

:::caution[Плохо vs Хорошо]
```
плохо: "напиши пост"
хорошо: "Ты — SMM для кофейни. Напиши пост 120 слов, тон дружелюбный, CTA — зайти на завтрак, 3 хештега"
```
:::

:::tip[Мышление]
ИИ — не замена мозга, а **ускоритель**. Ты — пилот, ИИ — турбина.
:::
