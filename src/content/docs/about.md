# О проекте

**Golovait** — гид по ИИ для новичков, которые знают "чуть-чуть про нейронки" и хотят старт без воды.

## Зачем

ИИ меняется каждую неделю. Мы собираем базу, проверяем на себе, отдаем коротко: карта, промпты копипаст, роадмап, ошибки.

## Как устроен сайт

- **Гайд** — 8 блоков, читай по порядку. Обновляем каждый месяц.
- **Блог** — свежие статьи от ИИ + редактура. Клепаем статику из `md` — быстро.
- **Статика** — `Starlight + Tailwind + Astro` на `GitHub Pages + golovait.ru`, `https`, `sitemap`, `RSS`.

## Как помочь

- Поделись ссылкой на [Гайд](/guide/01-chto-takoe-ii/) в ТГ
- Пришли тему для статьи — добавим
- Нашел ошибку — PR в `github.com/ctrl-fisht/golovait`
